# University Management System (Console-Based in C++)

A console-based C++ project designed to manage university operations such as student admissions, records, and fee details using file handling.

## Features
- Admin and student login system
- Add, update, and delete student records
- Calculate student aggregates
- Manage campus and program preferences
- View fee details and student data
- File handling for persistent data storage

## File Structure
- `src/` : Source code files
- `data/` : Text files storing student and user data
- `docs/` : Documentation files
- `README.md` : Project overview
